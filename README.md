# tcg-terminal

Employee terminal for TCG card intake, review, acquisition, and inventory workflows.

## Development

This project uses React, TypeScript, Vite, and React Router.

- `npm install` installs the project dependencies.
- `npm run dev` starts the local development server.
- `npm run build` checks TypeScript and creates a production build.
